## ⬇️ COMO BAIXAR (LEIA ANTES DE BAIXAR)

### ⚠️ NÃO use "Code → Download ZIP" — isso baixa SÓ o código-fonte, SEM o .exe!

### ✅ Opção 1 — Script automático (MAIS FÁCIL):

1. Baixe este arquivo: [BAIXAR-E-INSTALAR.bat](https://raw.githubusercontent.com/AlexCromy/nexus-arcade-windows/main/download/BAIXAR-E-INSTALAR.bat)
2. Salve numa pasta vazia (ex: Área de Trabalho)
3. Dê **duplo clique** nele
4. Ele baixa tudo sozinho, junta as partes e extrai o programa
5. Abra a pasta criada e dC� duplo clique em **Nexus Arcade.exe**

### ✅ Opção 2 — Manual:

1. Acesse a pasta [download](https://github.com/AlexCromy/nexus-arcade-windows/tree/main/download)
2. Baixe os 11 arquivos (NexusArcade.zip.part-aa até part-aj + JUNTAR.bat)
3. Coloque todos na mesma pasta
4. Execute JUNTAR.bat
5. Extraia o ZIP resultante
6. Abra **Nexus Arcade.exe**
